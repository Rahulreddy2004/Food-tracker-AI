# Food Tracker AI 🍎📸

A full-stack AI-powered application that recognizes food from images using Deep Learning, tracks nutrition, and helps manage your diet. This project utilizes a **Flask** backend with a custom **EfficientNetV2** model and a **React** frontend.

## 🚀 Features

* **AI Food Recognition:** Upload an image of food, and the model (trained on Food-101) identifies it.
* **Nutrition Tracking:** Automatically estimates calories and macros based on recognized food.
* **Barcode Scanner:** Built-in scanner for packaged food items.
* **Smart Dashboard:** Visual analytics of your daily calorie intake.
* **Chat Widget:** AI assistant for diet-related queries.
* **Authentication:** Secure login/signup system.

---

## 🛠️ Tech Stack

**Frontend:**
* React.js
* CSS3 (Custom Styling)
* Firebase (Authentication)

**Backend:**
* Python (Flask)
* TensorFlow / Keras (Deep Learning)
* EfficientNetV2B3 (Custom trained model)
